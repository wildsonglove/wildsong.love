From Claude Design to Live Website: A Complete Beginner's Guide This guide assumes zero technical background. Every step tells you exactly what to click and what you'll see. By the end, you'll have a real website on the internet with your own web address (like www.yoursite.com), and you'll know how to update it whenever you want. What you'll need: a computer with a web browser, an email address, and about $12/year if you want a custom web address (everything else is free). Time required: about 45–60 minutes the first time. Part 1: Understanding the Big Picture (2 minutes) A website is just a collection of files (code) that a computer somewhere on the internet "serves" to visitors. To get your Claude design online, you need three things: The files — the code Claude wrote for you (you already have this). A host — a company that stores your files and shows them to visitors. We'll use a free one called Netlify. A web address (domain) — like www.yoursite.com. Netlify gives you a free address (like yoursite.netlify.app), and you can optionally buy a custom one. We'll also use a free service called GitHub to store your files. Think of GitHub as a Dropbox for code — and the magic part is that whenever you change a file there, your website updates automatically. Part 2: Download Your Design from Claude (5 minutes) Open the conversation in Claude where your website design lives. Click on the design (the "artifact" panel showing your website). Look for a download button (usually a downward arrow icon, or a menu with "Download" in it), typically in the top-right corner of the artifact panel. Download the file. It will usually be named something like index.html or have a .html ending. Important: If the file is not named exactly index.html, rename it: Windows: Right-click the file → Rename → type index.html Mac: Click the file once, press Return, type index.html Why? index.html is the universal name for a website's home page. Hosts look for this exact filename. Create a new folder on your Desktop called my-website and put the file inside it. If your design is React code instead of HTML (the file ends in .jsx): ask Claude in your conversation, "Please convert this design into a single self-contained HTML file I can host anywhere." Claude will produce an index.html version, which is much simpler for beginners. Download that instead. Part 3: Create a GitHub Account and Upload Your Files (10 minutes) GitHub is where your website's files will live permanently. It's free. Create the account Go to github.com in your browser. Click Sign up (top-right corner). Enter your email, create a password, and choose a username. Follow the prompts (it may ask you to solve a small puzzle to prove you're human). Verify your email when GitHub sends you a confirmation message. If it asks questions about your plans, you can skip them or choose the Free plan. Create a "repository" (a project folder on GitHub) Once logged in, click the + icon in the top-right corner of GitHub, then click New repository. Under Repository name, type my-website (no spaces). Make sure Public is selected (this is fine — it only means the code is visible, and website code is visible to visitors anyway). Check the box that says Add a README file. Click the green Create repository button at the bottom. Upload your website file You're now looking at your new repository page. Click the Add file button (near the top of the file list), then click Upload files. Drag your index.html file from your Desktop folder into the upload area (or click "choose your files" and select it). Wait for the upload to finish (you'll see the filename appear with a checkmark). Scroll down and click the green Commit changes button. ("Commit" is just GitHub's word for "save.") Your website's code now lives safely on GitHub. If your computer died tomorrow, your website files would be fine. Part 4: Put Your Website Online with Netlify (10 minutes) Netlify is the host — it takes the files from GitHub and serves them to the world. Free for sites like yours. Go to netlify.com in your browser. Click Sign up. Choose Sign up with GitHub. (This is the key step — it links the two services so they can talk to each other.) A GitHub window will pop up asking you to authorize Netlify. Click Authorize. Once you're in the Netlify dashboard, look for a button like Add new site or Import an existing project and click it. Choose Deploy with GitHub (or "Import from Git → GitHub"). Netlify may ask for permission to see your GitHub repositories. Click Install/Authorize and allow access (you can allow access to all repositories or just my-website — either is fine). You'll see a list of your repositories. Click my-website. You'll see a settings page with fields like "Build command" and "Publish directory." Leave everything blank / as-is — a simple HTML site needs no build settings. Click the Deploy button at the bottom. Wait about 30–60 seconds. You'll see a progress screen, then a message that your site is live. Netlify shows you your new web address — something like https://silly-random-name-123456.netlify.app. Click it. That's your website, live on the internet. Anyone in the world can visit that address right now. Give it a nicer free address That random name is ugly. If you want your own custom address like www.yoursite.com, continue to Part 5. Part 5 (Optional): Buy a Custom Web Address (15 minutes, ~$12/year) A custom domain looks more professional.
